# Workflow AI pack (single flow) — sample shape

Fixed-scope remote pack from **Crom Services**. One client workflow, not a multi-agent suite.

## What you get
- One production-shaped flow: FAQ bot, WhatsApp triage, form → ticket, or n8n / LLM glue
- Clear in/out boundary, fixed price, ETA
- Runs on **your** tools and API keys (OpenAI, Anthropic, n8n, WhatsApp Business, etc.)
- Handoff notes so your team can own it after delivery

## What you do not get
- Crom Services paying for model tokens on a fixed fee
- A 2–4 agent “AI team” product
- Open-ended retainers (ask separately for a capped hourly slice)
