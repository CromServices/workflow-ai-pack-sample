# Workflow Agent Pack — sample shape

Fixed-scope remote pack from **Crom Services**. Board shape: FAQ/support lite. One business workflow — not a whole-company AI programme.

## One-liner
We seat specialist agents for one workflow on your tools—rules, escalate map, test checklist, handoff. You pay your own LLM/runtime.

## In
- One named workflow (FAQ/support, lead follow-up, ops digest, or similar)
- 2–4 specialist prompts **or** a single FAQ/support agent pack when board-shaped
- Hard stops + escalate map + test pack (happy / edge / refuse)
- Seating steps on **client** ChatGPT / Grok / Claude / etc.
- One revision round

## Out
- Crom Services bots/computer access; our API keys as free runtime
- Whole-company AI transformation
- Live chat staffing, Zendesk/KB programmes, workshops, MVP platforms
- GIS / FME / Esri / CiA
- Managed forever on our meter (separate retainer — not this pack)

## Runtime / keys
Client tools and client keys only. Crom usage = build + optional paid tune only.

## Vs other packs
- **Agent Review:** harden existing prompts (Reviewer) — not seating a team
- **Audit / status / API packs:** code/review/implement finishes — not agent seating
- **Managed desk retainer:** only if priced for usage; not the default Pack

## Price
Fixed **project fee** per scope (Nathan signs). Skip tiny ~US$250 widget gigs on boards. Warm/Malt: quote as project, not hourly token soak.

## Client checklist
1. Name the one workflow (one sentence)
2. Which client accounts/tools hold the agents
3. Where secrets live (you keep the keys)
4. Done-when test (happy / edge / refuse)
